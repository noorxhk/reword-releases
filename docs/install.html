Install guide

Up and running
in five minutes.

Hold fn to dictate in English, Urdu or Hindi. Select text and press ⌥2 to rewrite it. Here's everything, step by step.

macOS 26 or laterApple silicon (M1 or newer)Free
Fastest · Terminal

Open Terminal, paste this and press Return. It installs the latest version and opens it. Then jump to step 4.

  1. Download the DMG Terminal: skip

    Click Download Reword. It saves Reword-x.y.z.dmg to your Downloads folder.

  2. Drag Reword to Applications Terminal: skip

    Open the downloaded DMG. Drag the Reword icon onto the Applications folder, then open Reword from Applications.

    Reword
    →

  3. Click “Open Anyway” Terminal: skip

    The first time, macOS says Reword can't be opened because it isn't from the App Store. Click Done, then go to System Settings › Privacy & Security, scroll to the bottom and click Open Anyway. Enter your Mac password if asked. You only do this once.

    System Settings
    Privacy & Security › Security
    “Reword” was blocked to protect your Mac.Open Anyway

  4. Allow Accessibility and Microphone

    Reword asks for Accessibility so it can type where your cursor is and read the text you select. Turn on Reword in System Settings › Privacy & Security › Accessibility. The first time you hold fn, allow the Microphone.

    System Settings
    Privacy & Security › Accessibility
    Reword

    Reword's Get started tab shows a live check for each of these.

  5. Free up the fn key

    Out of the box, fn opens the emoji picker. In System Settings › Keyboard, set Press 🌐 key to to Do Nothing.

    System Settings
    Keyboard
    Press 🌐 key toDo Nothing ⌄

    Then in Reword's Settings › Voice, pick the language you speak. Dictation works from here.

  6. Add a free AI key for cleanup and rewriting

    Reword uses your own free key, so there's no account and no bill. Pick one service, sign in there and create a key:

    GroqFastest · the default Google GeminiStrong with Urdu OpenRouterMany free models

    In Reword, open Settings › AI, choose the same service, paste the key and click Test key. The key stays in your Mac's Keychain and only goes to that service.

You're set. Try it.

If something's off

Shortcuts do nothing

Check Accessibility in step 4. If Reword is already on, remove it from the list with −, then add it again.

fn opens the emoji picker

Step 5: set “Press 🌐 key to” to Do Nothing.

Urdu comes out wrong

Reword › Settings › Voice › I speak › Urdu + English. It understands English too.

“Limit is used up”

Free keys have limits. Wait a while, or switch service in Settings › AI.

Terminal says “needs macOS 26”

Reword only runs on macOS 26 or later with an Apple silicon Mac.
